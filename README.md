# Indian Food Cuisine Analysis

## Project Overview

This project analyzes and compares various attributes of dishes across different dietary preferences and cuisines using Python data analysis libraries. The analysis focuses on rating distribution, dish complexity, cooking time variation, diabetic-friendly and sugar-free dishes, and the most common cuisine types for different courses.

---

## Objective

The main objective of this project is to:

- Analyze rating distributions between high-protein vegetarian and non-vegetarian dishes.
- Compare dish complexity across Indian and international cuisines.
- Study cooking time variations among different vegetarian diet types.
- Identify diabetic-friendly and sugar-free dishes.
- Determine the most common cuisine type for each course.

---

## Technologies Used

The project is developed using the following technologies and libraries:

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- OpenPyXL
- Jupyter Notebook
